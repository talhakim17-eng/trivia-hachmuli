# 🧠 חידון חכמולי

משחק טריוויה בעברית לילדים בגילאי 7-9, עם 5 רמות קושי אדפטיביות ובנק של ~460 שאלות מובנות.

## 🚀 התקנה והרצה מקומית

```bash
# 1. התקנת חבילות
npm install

# 2. הרצה מקומית
npm run dev
```

האתר יפתח בכתובת `http://localhost:5173`

## 📦 העלאה ל-Vercel

### דרך 1 — דרך GitHub (מומלץ)
1. צור חשבון ב-[GitHub](https://github.com) (אם אין לך)
2. צור repository חדש והעלה את הקבצים
3. היכנס ל-[Vercel](https://vercel.com) והתחבר עם GitHub
4. לחץ "New Project" → בחר את ה-repository
5. Vercel יזהה אוטומטית שזה פרויקט Vite — לחץ Deploy
6. תוך דקה תקבל כתובת כמו `trivia-hachmuli.vercel.app`

### דרך 2 — דרך Vercel CLI
```bash
# התקנת CLI
npm install -g vercel

# העלאה
vercel
```

## 🎮 איך המשחק עובד

- **10 שאלות** בכל משחק, נבחרות רנדומלית מבנק של ~460 שאלות
- **5 רמות קושי** שמתכווננות אוטומטית:
  - 8+ תשובות נכונות → עולים רמה
  - 6-7 נכונות → נשארים
  - 5 ומטה → יורדים רמה
- **טיימר של 3 דקות** לכל המשחק
- **שאלות לא חוזרות** עד שכל הבנק נוצל

## ➕ הוספת שאלות

כדי להוסיף שאלות, ערוך את קבצי ה-JSON ברמה המתאימה. כל שאלה בפורמט:

```json
{
  "question": "טקסט השאלה?",
  "options": ["אפשרות 1", "אפשרות 2", "אפשרות 3", "אפשרות 4"],
  "correct": 0,
  "explanation": "הסבר קצר 🎯"
}
```

`correct` הוא האינדקס (0-3) של התשובה הנכונה.
